# A membership database with an agent as the door

Members, levels, renewals, events, registrations, receipts and committee records are ordinary Postgres records. Claude Code, Codex, OpenCode or Cursor reads the same instructions and runs the same commands. The agent is replaceable; the database is yours.

A screen gives members self-service joining, profile updates and online booking. Mobile apps provide a convenient event check-in flow. Offline access, live notifications, drag-and-drop website editing and payment-provider connections require additional software. This base is for the membership administrator, not a self-service member portal.

Read-only HTML snapshots cover the membership week and committee review. They contain personal data, so keep them private. They are not a live application and need regeneration after changes. Documents are drafts and never send.
