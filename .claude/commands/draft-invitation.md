# draft-invitation

Read CLAUDE.md. Run:

```bash
npm run membership -- draft-invitation <member> <event>
```

Requires recorded marketing consent. Read the event and member first. Save the draft path. Never send.

Use --json when composing analysis. Ambiguous names list candidates and exit 1; resolve the candidate before continuing. Drafts never send.
