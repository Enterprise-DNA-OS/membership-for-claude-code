# Customise

Read CLAUDE.md and the current schema. Translate the requested field, level name or rule into a concrete change. Back up real data. Write a new numbered migration, update fields.json and the CLI, add meaningful checks, run npm test, then apply with npm run migrate. Do not rewrite an applied migration. Document the new field in docs/cli.md. Rule changes cite their source; association policy must not be described as law. Nothing sends or publishes.
