# draft-renewal

Read CLAUDE.md. Run:

```bash
npm run membership -- draft-renewal <member>
```

Read the current member and invoice records. Save the draft path. Review dates and language before giving it to the operator. Never send.

Use --json when composing analysis. Ambiguous names list candidates and exit 1; resolve the candidate before continuing. Drafts never send.
