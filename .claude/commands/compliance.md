# compliance

Read CLAUDE.md. Run:

```bash
npm run membership -- compliance
```

Read docs/compliance.md. Report each rule, record and evidence gap. NZ labels scope the NZ checks. Recorded constitutional deadlines must be verified for the association. This is a record check, not certification.

Use --json when composing analysis. Ambiguous names list candidates and exit 1; resolve the candidate before continuing. Drafts never send.
